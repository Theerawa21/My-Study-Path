# My Study Path

ระบบสำรวจความสนใจและวางแผนการเรียนต่อหลังจบชั้นมัธยมศึกษาปีที่ 3

## ฟังก์ชันหลัก

- นักเรียนเข้าสู่ระบบด้วยรหัสประจำตัวนักเรียน
- สำรวจวิชาที่ชอบ วิชาที่ทำได้ดี สิ่งที่สนใจ และจุดเด่น
- เลือกเส้นทางหลังจบ ม.3: ม.4 / ปวช. / หลักสูตรเฉพาะทาง / อื่น ๆ / ยังไม่แน่ใจ
- ระบุแผนการเรียนหรือสาขาที่สนใจสูงสุด 3 อันดับ
- ระบุสถาบันที่อยู่ในใจและอาชีพที่สนใจ
- ระบุปัจจัยในการตัดสินใจ บุคคลที่ปรึกษา และข้อมูลที่ต้องการเพิ่มเติม
- ประเมินระดับความมั่นใจ 1–5
- บันทึกร่างและยืนยันข้อมูล
- Dashboard ครูสำหรับดูภาพรวม ค้นหา และบันทึกคำแนะนำ

## ฐานข้อมูล

ระบบออกแบบให้ใช้ Google Sheet `ระบบสำรวจความสนใจ` เป็นฐานข้อมูล โดย Apps Script ใน `apps-script/Code.gs` อ้างถึง Spreadsheet ID ที่กำหนดไว้แล้ว

## การเชื่อม Google Apps Script

1. เปิด Google Sheet `ระบบสำรวจความสนใจ`
2. ไปที่ **ส่วนขยาย > Apps Script**
3. นำโค้ดจาก `apps-script/Code.gs` ไปวางในไฟล์ `Code.gs`
4. กด **Deploy > New deployment > Web app**
5. ตั้งค่า Execute as: **Me**
6. ตั้งค่า Who has access: **Anyone** (หรือการตั้งค่าที่เหมาะกับบัญชี Workspace ของโรงเรียน)
7. Deploy และคัดลอก URL ที่ลงท้ายด้วย `/exec`
8. เปิดไฟล์ `config.js` ใน GitHub แล้วใส่ URL ดังกล่าวใน `API_URL`

```js
window.MY_STUDY_PATH_CONFIG = {
  API_URL: 'https://script.google.com/macros/s/...../exec',
  APP_NAME: 'My Study Path',
  SCHOOL_NAME: ''
};
```

## เตรียม Google Sheet

ชีต `นักเรียน` ต้องมีคอลัมน์:

`รหัสนักเรียน | ชื่อ | นามสกุล | ระดับชั้น | ห้อง | เลขที่ | สถานะ`

ถ้าใช้คอลัมน์สถานะ ให้กำหนดเป็น `ใช้งาน` หรือปล่อยว่าง

ชีต `ตั้งค่า` ช่อง **B4** ใช้กำหนดรหัสครูสำหรับเข้า Dashboard
